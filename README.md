# Paddle in Sync

叠滘龙舟文化互动体验游戏试玩版。

## 在线试玩

[打开浏览器试玩](https://pub-080dd0c1bc8b433d8059c847de1bb58d.r2.dev/index.html)

建议使用桌面浏览器。首次载入约需下载 1.5 GB，请保持网络连接并耐心等待。浏览器版使用 W 前进、S 减速、A / D 转向；浏览器不能直接使用本机串口船桨。

## Windows 本机版

从 [Releases](https://github.com/jane2632626881-a11y/paddle-in-sync/releases) 下载 **Paddle in Sync-Windows.zip**，解压后运行 `Paddle in Sync.exe`。本机版保留串口船桨交互，项目配置使用 COM9、COM10、COM11，波特率 115200；需按实际硬件连接设置串口。实体船桨尚未在这台电脑上完成联机实测。

## 发布内容

Releases 中提供 Windows 版和 WebGL 版压缩包。WebGL 文件已部署到 Cloudflare R2，网页试玩地址见上方。完整 Unity 工程没有包含在这个发行仓库中。
